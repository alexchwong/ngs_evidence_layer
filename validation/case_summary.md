# NEL-focused case set — clinician-authored validation set

## Case 1A — DNMT3A/TET2-mutated AML

### Case summary

Pancytopenia. Marrow shows 30% myeloid blasts. Provisional diagnosis: **acute myeloid leukaemia (AML)**.

**NGS:** `DNMT3A` NM_022552.5:c.2645G>A, p.(Arg882His), VAF 42%; `TET2` NM_001127208.3:c.1132_1133del, p.(Gly378CysfsTer11), VAF 36%.

**Cytogenetics:** Normal.

### Marking criteria

#### R1 — Diagnosis and classification

- **R1C1.** Confirm **AML**.
- **R1C2.** State that DNMT3A R882H and truncating TET2 support clonality but do not independently define another AML entity.
- **R1C3.** State that DNMT3A R882H and truncating TET2 do not independently define AML with myelodysplasia-related genetic abnormalities.

#### R2 — Prognostic interpretation

- **R2C1.** Assign the applicable **ELN 2022 intermediate-risk** category from the supplied normal cytogenetics and absence of an ELN favourable- or adverse-defining molecular finding.
