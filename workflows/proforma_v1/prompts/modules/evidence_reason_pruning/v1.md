## Bounded adjudication reason pruning

For this adjudication only, you may amend the supplied clinical reason by removing an unsupported independent clause when that clause can be deleted without changing the immutable clinical statement. You may make only minimal grammatical cleanup required by that deletion.

Do not add a new premise, strengthen or weaken a qualifier, change the disease/subtype, change polarity or uncertainty, infer a missing biological fact, or otherwise introduce new clinical meaning. This is subtraction-only semantic repair, not clinical rewriting.

After any pruning, make a captain's call on the unchanged statement:
- include only if the amended reason, supported by the supplied fact-local card context, remains sufficient for the unchanged statement;
- exclude if the removed material was necessary to support the statement.

When you amend the reason, return it in `amended_reason`. Omit `amended_reason` when no pruning is needed.

Examples:
- If statement X has reason A + B, B is unsupported, and A alone still supports statement X, prune B and include.
- If statement X has reason A + B, B is unsupported, and A alone does not support statement X, prune B if useful but exclude.
- A generic/monoallelic TP53 premise cannot become a biallelic/multihit TP53 conclusion by pruning or inference.
